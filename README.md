# Modelo ASCIIPSEL
 Site da segunda etapa do processo seletivo ASCII EJ
 
 
# 🌐 Site HTML e CSS Puro

Este repositório contém um site desenvolvido utilizando apenas HTML5 e CSS3. É um projeto ideal para estudos de estruturação semântica, estilização e organização de um site estático sem o uso de frameworks ou bibliotecas externas.

![preview do site](https://raw.githubusercontent.com/matheus-mvk/SITE-HTML-E-CSS-PURO/main/screenshot.png)

## 🚀 Demonstração

Você pode visualizar o site localmente abrindo o arquivo `index.html` em qualquer navegador moderno.
